個人表現分析

從每次訓練，看見跨日期的變化。

可直接讀取 EXE 旁的 Data，或匯入其他日期的紀錄。資料只在本機分析。

    先載入訓練紀錄

    選取 Data 資料夾，或一次匯入多份 CSV／JSON。相同測驗不會重複計入。

    任務表現趨勢

    角度誤差越小代表越接近目標；命中率須在相同門檻下比較。

    連線分開不同模組、追蹤來源及刺激設定。命中率另外依實際門檻分組；同日混用門檻時不合併顯示百分比。

    各方向的注視追蹤表現

    依訓練方向整理；追隨含去程與回程，注視僅含端點停留，跳視排除前 200 ms。

    選擇上方「方向」可查看該方向跨日期的趨勢。VOR 1x 為中央目標；移動 VOR 依當時目標位置分方向。

    八方向複視角度

    依實際填答時間跨模組整理；沿用問卷只計一次。

    角度以正前方為 0°。「無複視」表示測試範圍內未出現複視，保留文字狀態，圖上不當成 0°。日期依本機時區顯示。

    計算方式與資料限制

    將每筆有效 gaze 與同一來源時間的目標座標換成螢幕視角，再計算水平與垂直差值。右、上為正。偏差為加權平均誤差；SD₂D 為水平與垂直誤差變異量相加後開根號；RMSE 為兩軸誤差平方和的加權平均再開根號。

    使用原始 Accuracy 的有效計分時間作權重。同日彙整累加時間與誤差統計量，不平均各次百分比。沒有時間權重的舊資料採樣本加權，分開比較；沒有逐筆目標資料的 JSON 只提供已記錄摘要。

    命中率沿用原始命中旗標；角度誤差以兩軸視角差重算，與舊版單一距離換算法可能不同。

    這些是任務表現描述，包含受試者行為與儀器誤差，不等於儀器校正精度或視力表結果。缺資料不當成眨眼；不補值或增加前後排除窗。
