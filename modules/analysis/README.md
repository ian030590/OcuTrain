# OcuTrain Analysis

獨立的本機分析入口、計算核心與測試。訓練程式不載入此目錄的計算程式；桌面宿主只提供開啟視窗、讀取 `Data/` 與儲存摘要的命令。

## 執行與打包

在專案根目錄執行 `npm run prepare:analysis`，將網頁資源複製到產生的 `wwwroot/analysis/`。Tauri 的開發及建置前置命令會自動執行這一步。資源隨 EXE 內嵌，不需要另外分發此目錄或安裝分析服務。

以靜態 HTTP 伺服器開啟 `wwwroot/analysis/index.html` 可測試瀏覽器模式，使用檔案或資料夾匯入。桌面模式從訓練頁面上方的 Analysis 開啟獨立視窗，自動讀取 EXE 旁的 `Data/`；摘要寫入 `Data/Analysis/`，不修改原始紀錄。

## 邊界

- `model.mjs`：CSV／JSON 解析、來源標準化、測驗與問卷去重、方向誤差計算、時間加權彙整及 CSV 編碼；不依賴 DOM、Tauri 或訓練程式。
- `app.mjs`、`charts.mjs`、`index.html`、`styles.css`：分析介面、篩選、SVG 趨勢圖與匯出。
- `tests/model.test.cjs`：以可驗算資料測試計算、舊格式、空值、去重及匯出安全性。
- `src-tauri/src/analysis.rs`：宿主整合與受限制的本機檔案存取；只讀 `Data/` 直屬 CSV／JSON，單檔上限 64 MiB。

獨立執行測試：`npm --prefix modules/analysis test`。根目錄 `npm test` 也包含此測試集。

## 支援的資料

以 OcuTrain 逐筆 CSV 為主要來源，包含原始 gaze、同一來源時間的目標、方向、計分資格及 `accuracy_delta_t_ms`。新版 CSV 的 `Module Settings` 與 `Viewport Size` 保留完整比較條件與視窗幾何；較舊 CSV 可讀取，但缺少設定及幾何時會列出限制。

JSON 支援單次測驗、測驗陣列及 jsPsych 測驗 CSV。舊 JSON 的 `gaze_path` 缺少逐筆目標，不反推刺激軌跡，只保留命中摘要及複視問卷；匯入同次 CSV 後合併為一筆。若 JSON 有 `gaze_records`，可直接計算方向表現。

檔案需包含受試者 ID、session ID、有效模組與日期。格式錯誤逐檔列出，不以空值冒充 0。CSV 的引號、逗號、換行及 UTF-8 BOM 皆可處理；損壞的檔案不自動猜測修復。匯出會防止受試者文字被 Excel 解釋為公式。

## 指標

以螢幕中心為原點，依實體尺寸、觀看距離及像素比例計算 gaze 與目標的水平、垂直視角；水平右、垂直上為正。若逐筆已有目標視角，優先使用該值；舊 CSV 未記錄視窗尺寸時以全螢幕推估原點並標註限制。

令同一時間的角度差為 `e_h`、`e_v`，權重 `w` 為該樣本實際有效計分時間：

- 偏差：`mean_w(e_h)`、`mean_w(e_v)`，大小為兩者平方和開根號。
- 平均距離誤差：`mean_w(sqrt(e_h² + e_v²))`。
- RMSE：`sqrt(mean_w(e_h² + e_v²))`。
- SD₂D：`sqrt(var_w(e_h) + var_w(e_v))`，使用母體加權變異量。
- 命中率：`命中有效毫秒 / 全部有效計分毫秒 × 100%`，沿用原始空間命中旗標。

只納入有效、可計分且權重大於 0 的樣本。Fixation 只用端點停留，Pursuit 使用去程與回程，Saccade 不納入中央十字及最初 200 ms。方向沿用訓練方向；移動 VOR 依當時目標位置分至八方向，距中心半像素以內歸中央。

同日以統計量與時間相加後重算，不平均各次百分比。不同受試者、模組、來源、刺激設定與加權方式分開。角度誤差不依命中半徑分線；命中率依半徑分線。同日混用半徑時，一般誤差表不合併其百分比。完整設定與門檻保留在摘要。

這些是任務表現描述，不等同儀器校正精度。沒有時間權重的舊資料以樣本加權計算角度誤差，不推算方向命中率。未追蹤、無有效座標或缺少幾何時顯示未提供。

角度誤差使用兩軸視線角度差的向量，與訓練程式舊有 `distance_error_deg` 的單一距離換算法不完全相同；命中率仍採原始資料的空間命中旗標，不以分析端新角度重新判定。

## 複視

以受試者、原問卷的 `source_session_id` 及 `submitted_at` 去重。沿用問卷放在原填答日期，日期按分析電腦時區顯示，並保留原 ISO 時間。複視整理只受受試者與日期篩選影響，不受任務模組／追蹤來源篩選影響。

0° 是有效的起點；「測試範圍內無複視」與「未測量」分開。無複視不轉成 0、無限大或任意最大角度，圖線在該筆中斷。這個分析入口不偵測眨眼，也不對無效或缺資料區段補值。
